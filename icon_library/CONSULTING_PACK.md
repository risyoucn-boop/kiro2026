# 咨询框架包 · 200 个

> 本包是 **1000 个通用图标包** 的补充包，专门覆盖战略汇报、转型路线图、组织诊断、运营优化等场景的**框架图标**。
>
> 每个图标对应一个**公开的商业方法论框架**（2x2 矩阵、SWOT、五力、PDCA、S-曲线、飞轮…），不是通用名词图标。

---

## 与 1000 包的区别

| | 1000 通用包 | 200 咨询框架包 |
| --- | --- | --- |
| **定位** | 业务名词图标（盾牌、机器人、邮件、客户头像…） | 方法论框架图标（2x2矩阵、漏斗、S曲线、飞轮…） |
| **风格** | 单图形+徽章变体 | 每个图标是一个独立框架 |
| **分类** | 12 个业务场景 | 6 个咨询维度 |

| **数据库** | DATA/TRAIN/CUST/SALE/RISK/FLOW/AI/KNOW/FIELD/ORG/ALERT/SHOW | STRAT/FLOW/ORG/CHART/DIAG/CONCEPT |

**两个包可以一起用** — 1000 包做业务图示的"名词"，200 包做战略文档的"框架"。

## 关键技术点（同 1000 包）

- 每个图标都是 **PowerPoint 原生 `custGeom` 形状**（OOXML 标准）
- 复制到业务 PPT 后，**形状填充 → 一键改色**
- WPS / Office 365 / Office 2016+ / Keynote 全兼容
- 单色 `solidFill` + 无 stroke，确保一次填充覆盖整个图标

## 使用流程

```text
1. 打开 Excel 检索表
2. 在 [中文关键词] 或 [英文关键词] 列搜索：
   - 战略类：矩阵 / 象限 / 漏斗 / 价值链 / 飞轮 / 拐点
   - 流程类：PDCA / 路线图 / 看板 / DMAIC / OODA
   - 诊断类：SWOT / 鱼骨 / 5Why / 帕累托 / 力场
   - 数据类：瀑布 / 桑基 / 雷达 / 帕累托 / 子弹
   - 概念类：S曲线 / 网络效应 / 飞轮 / 反脆弱 / J曲线
3. 拿到编号（例 STRAT-007 = 三层增长曲线）和 PPTX 页码
4. 打开 PPTX，跳到对应页，单击图标 Ctrl+C
5. 在你的业务 PPT 里 Ctrl+V
6. 选中图标 → 形状格式 → 形状填充 → 选品牌色
```

**推荐配色**：

| 名称 | HEX | 适用 |
| --- | --- | --- |
| 深咨询蓝 | `#1F4E79` | 战略文档主色 |
| 深石墨 | `#2D3748` | 通用主色 |
| 强调橙 | `#FF6A00` | 重点高亮 |
| 警示红 | `#E53E3E` | 风险/预警 |
| 达成绿 | `#38A169` | 成就/达成 |
