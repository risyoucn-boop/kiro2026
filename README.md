## 这次为什么不直接用 SVG

你之前提的方案是「SVG → 插入 PPTX → 右键转换为形状」。这个流程的真实问题：

1. **手动转换不可批处理**。1000 个图标手动点 1000 次"转换为形状"是不可能完成的。
2. **WPS 对 SVG 转形状的支持不稳**。某些 SVG 转换后会变形、丢细节、变黑。
3. **不同 Office 版本入口不一致**。

**这次的做法**：直接用 Python 生成原生 PowerPoint `custGeom` 形状（OOXML 标准元素）写进 PPTX。

| | 旧方案 (SVG插入+转换) | 本方案 (custGeom) |
| --- | --- | --- |
| 形状底层 | SVG → 需手动转换 | 原生 PowerPoint Shape |
| 改色操作 | 转换后才能改 | 选中 → 形状填充 → 改完 |
| WPS 兼容 | 不稳定 | 稳定（OOXML标准） |
| Office 版本兼容 | 部分支持 | 全版本支持 |
| 1000 个批量制作 | 不现实 | ✅ 已完成 |

```text
1. 打开 Excel 检索表
2. 在中文/英文关键词列搜「预警」「转化」「对齐」「闭环」…
```

## 技术细节

### 图标在 PPTX 里到底是什么

每个图标 = 一个 `<p:sp>` 节点，里面包含 `<a:custGeom>`，路径用 `<a:moveTo>` / `<a:lnTo>` / `<a:cubicBezTo>` / `<a:close>` 描述。
填充用 `<a:solidFill><a:srgbClr val="2D3748"/>`，描边设为 `<a:ln w="0"><a:noFill/>`。这样：

- 选中图标 → "形状填充" 直接覆盖 solidFill
- 没有 stroke，所以一次填充就把整个图标重新着色，不会留下黑色描边
- 全部填充用同一个颜色，所以不需要"取消组合"分别改

### 复杂形状的几何处理

1. **环形（如盾牌轮廓、放大镜）**：用 even-odd 填充规则的复合路径，外圈正向 + 内圈反向，形成"挖洞"效果。
2. **齿轮**：用极坐标算法生成 8/9 齿外轮廓 + 中心圆孔。
3. **箭头**：7 点多边形（尾部矩形 + 三角箭头），可以指任意方向。
4. **椭圆/圆**：用 4 段三次贝塞尔曲线逼近（kappa = 0.5523），任何 Office 版本都能精确渲染。

### 为什么不用 SVG 内嵌

PPTX 支持 SVG 内嵌（Office 365 的新功能），但有问题：

1. SVG 在 PPTX 里是 `<p:pic>` 节点，**不是形状**。改色要先"转换为形状"，又回到老问题。
2. WPS 不支持 SVG 内嵌或转换很不稳。
3. PowerPoint 2016 完全不支持。

`custGeom` 是 OOXML 标准（自 Office 2007 起），所有版本都支持。

## 项目结构

```text
icon_library/
├── icons_svg/                                                # 1000 个 .svg 原始文件
│   ├── DATA-001.svg ... DATA-088.svg
│   ├── TRAIN-001.svg ... TRAIN-083.svg
│   └── ... (12 个分类)
├── output/                                                   # 最终交付
│   ├── PPT图标语义库_可改色形状_1000.pptx
│   ├── PPT图标语义库_可改色形状_1000_检索表.xlsx
│   └── PPT图标语义库_可改色形状_1000_索引.csv
├── _preview/                                                 # 预览图（视觉验证）
│   ├── contact_sheet.png        ← 12 分类各取 3 个图标的全集预览
│   └── risk_grid.png            ← RISK 分类一页内的实际网格布局
└── generator/                                                # 可复用的源代码
    ├── primitives.py    # 几何原语 + 高层形状下沉到低层路径
    ├── svg_writer.py    # SVG 输出
    ├── pptx_writer.py   # PPTX 输出（custGeom XML 直接构造）
    ├── builders.py      # 形状构建函数库（150+ 个）
    ├── modifiers.py     # 16 种角标徽章
    ├── bases.py         # 169 个基础概念定义（12 个分类）
    ├── registry.py      # 基础 × 徽章 = 1000 个图标的注册表
    └── build.py         # 主构建脚本（一键产出全部交付物）
```

## 重新生成

```bash
cd icon_library/generator
pip install python-pptx openpyxl lxml
python build.py
```

输出 1000 个 SVG（约 0.1 秒）+ PPTX（约 3 秒）+ Excel（约 0.7 秒），总耗时 ~4 秒。

## 后续扩展建议

如果你以后要扩到 3000 个：

1. 在 `bases.py` 里给每个分类加 10~15 个新的基础概念（按业务术语词频选）
2. 在 `modifiers.py` 里加更多徽章（例如 `cloud`/`mobile`/`global`）
3. 在 `registry.py` 把 `BADGES_PER_CAT` 调到 7~9
4. 重新跑 `build.py`

整个生成器是声明式的，1000 → 3000 不需要改架构。
